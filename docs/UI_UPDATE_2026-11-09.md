# UI 更新记录 · 0.3.26

本轮接续已有未提交的稳定性修复和 Harness UI 修改，集中完善展示和连接配置流程。

## 页面变化

- 生活页：可点击的连接摘要、同步时间与电量；缩短屏幕时间卡片，保留水面玻璃风格；任务与提醒入口、大字体时单列的快捷操作。未配置状态依据实际配置判断，缺少使用情况权限时不显示虚假的 0 分钟。
- 我的：纸笺风格的个人资料卡，独立的「连接与设备」「日常与偏好」分组，完整保留权限、任务、隐私和自主功能入口。
- 动态：与其他两页使用同一标题组件，现有筛选、记录与任务详情行为不变。
- 连接：按 AstrBot 服务、手机控制、可选 Relay 分组，诊断可折叠；主按钮是保存并测试插件连接，次按钮仅保存。键盘弹出时按钮仍可见，关闭有修改的表单需明确放弃。新输入的凭据只留在 composition 内，保存值不回显；保存时保留已有的其他连接字段。
- 深浅主题使用明确文字颜色，增大最小标签字号，状态同时有文字说明。

## 验证与复现

构建使用 JDK 17 与现有 Android SDK；未升级依赖。

```powershell
.gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:processReleaseMainManifest --max-workers=2
```

27 项 JVM 单元测试通过；lint 0 错误、34 警告。修正深色文本后再次构建和运行 lint 通过。Release manifest 已确认不含调试预览 Activity。

`app/src/debug/` 提供 `VisualReviewActivity`，使用独立的 FakeAppState 显示样例，不修改正式连接配置；仅 debug APK 包含这个入口。示例：

```text
adb shell am start -n com.tauru.astrbotphoneagent/.ui.VisualReviewActivity --es scenario ready --ei tab 1
```

`tab` 为 0 动态、1 生活、2 我的；`scenario` 可用 `ready`、`empty`、`error`。所有截图中的数据和测试连接结果均为调试样例，不作为真实服务器或手机控制链路连通证据。正式入口仍是 `MainActivity`。

视觉验收覆盖 360×800 / 412×915 dp、深浅主题、1.0 / 1.3 字体；连接表单另检查键盘、保存反馈、错误反馈和放弃编辑。屏幕内容支持滚动，长页面的下方条目不强求全部塞进首屏。

后续已在 Honor RMO-AN00 / Android 13、App 0.3.26 上确认 Tailscale 直连、Shizuku 状态、Relay ping 和受限多步任务执行正常；长时间后台保活与系统恢复仍未做专项验证。
